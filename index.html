Impossibles

Minecraft server engineering. Game modes, anticheat, and the machinery underneath.

Java · Paper · PacketEvents · Fabric · Linux

I write the plugin that runs the mode, the anticheat that keeps it honest, and the panel that keeps the box online.

Most of what I build sits underneath a Minecraft PvP server, in the half nobody posts screenshots of. A game mode is easy to demo and hard to keep standing at eighty players. An anticheat is easy to write and hard to trust. The second half of both is the work I care about.

My defaults come from that. Loops over untrusted data get a ceiling. A failed read returns nothing rather than stale bytes. Anything that depends on a game version lives in a config file, because game versions rot and editing text beats rebuilding.

Anticheat is the thread through all of it. A detection is only as good as the understanding behind it, so most of the time goes into working out how a cheat actually moves packets around, then finding the one signal that separates it from a player whose frame rate dropped. That is also why my checks ship alert‑only until their false positive rate earns them a ban threshold. A check that bans an honest player costs more than a check that misses.

Away from the servers I like small tools with no dependencies, and build systems that need no supervision. One of these puts an iPhone app on the App Store from a Windows laptop without anyone signing in to App Store Connect.

The work

Mace Zonewars

Paper 1.21.11 · Java 21 · no database, no web service, no NMS

Eighty players, four teams of twenty, one hill. Each team lives in a tower a hundred blocks above the arena, glides down to fight, and recalls up to regear. A storm closes on the middle and drags the towers inward with it, so the last teams alive finish shoulder to shoulder instead of stalling on opposite edges of the map.

Coins are personal and buy gear. Enemy heads are a team currency, banked by anyone, spent on perks all twenty players receive. Arena, towers, loot and spectator camera are generated fresh per match, and setup is one command run from the hub.

What made it buildable was a scaled test mode that runs the entire match loop solo in about two minutes. Without that, changing one number needs twenty testers.

Aegis

Paper 1.21.11 · PacketEvents · 78 checks · no NMS

A behavioural anticheat with player‑facing replays. The weapon coverage targets cheats that actually circulate: a forged movement round trip correlated against a mace smash, the millisecond gap between selecting a spear and the stab packet landing, same‑target bursts arriving faster than hurt immunity permits.

Every check reads the same four settings, and a ban threshold of zero means alert‑only. Detections I do not trust yet ship that way deliberately. Automatic punishment needs corroboration from an independent check, so a single noisy signal can never ban on its own, and every violation funnels through one service instead of seventy‑eight scattered call sites.

The replay side lets a moderator watch a flagged sequence back rather than trust a number in a log line.

OniPlugin

Paper 1.21.11 · Java 21 · LuckPerms, ViaVersion, voice chat

The whole server experience in one plugin: duels, free‑for‑all queues, spectating, parties, moderation tooling and a Discord bridge.

The menus are built on the 1.21.6 server dialog system with custom bitmap fonts, rather than chest inventories full of dyed wool. That is the difference between an interface that looks designed and one that looks improvised. Arenas load from litematic schematics, so map makers work in a normal editor.

onihost

Ubuntu 24.04 · Incus system containers · Caddy, Postgres, Docker

One laptop turned into a hosting platform. Twenty‑four gibibytes for the game container, six for the backend, on a thirty‑two gigabyte machine. That leaves about one gigabyte, which is the whole reason these are system containers and not virtual machines: per‑guest kernels do not fit in the gap.

The game container is pinned to the performance cores with swap disabled. The backend gets the efficiency cores. Both carry hard ceilings so neither can starve the host.

Installation is a USB stick. A Windows installer, built with the compiler already sitting inside Windows, downloads the current Ubuntu release, checks it against the published hashes, writes an autoinstall seed and sets a one‑time boot. Two interruptions, then it finishes alone.

Emberline

Swift · XcodeGen · GitHub Actions · App Store Connect API

An offline habit tracker for iPhone, and the pipeline that ships it from a Windows laptop.

There is no Xcode project in the repository. It is generated from a YAML file on the build machine, which is the trick the whole thing rests on. The release run creates the bundle identifier and the App Store record, sets the privacy labels, tests the streak maths, then builds, signs and uploads.

Freelook

Fabric · Minecraft 1.21.11 · AGPL‑3.0 fork

Camera work, carried past what the original mod did. Third person placement with clamping, so the camera stops at a wall instead of passing through it, and a perspective lock that turns the view key into two states rather than three.

The locked aim persists between activations. That is the detail that makes it usable mid‑fight instead of a novelty.

discord‑name‑check

Java 21 · zero third‑party dependencies

Finds which short, sayable usernames are still free. Everything it uses ships with the JDK, including a two hundred line JSON reader, so the program can be read end to end before it is run. That is the point of it.

It asks one name at a time, slowly, waits out the rate limit, and flushes results per row, so stopping it loses nothing and the next run skips what it already knows. It holds no token and claims nothing.

Win11Debloat Launcher

C# · .NET Framework 4.x · builds with no SDK installed

A PowerShell script folded into one executable. The script rides along as a managed resource, unpacks to a private temporary file, runs with every argument forwarded, then deletes itself. The exit code comes back out.

It compiles with the C# compiler already present on every Windows install, at maximum warning level with warnings as errors, so there is nothing to install before building it.
